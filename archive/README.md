# Historical design files

The files in this directory document earlier Haute & Hazard versions. They are preserved for design history and comparison. **They are not the current playtest rules or card pool.** Start with the [v7.8 playtest guide](../docs/PLAYTEST_START_HERE.md) for current multiplayer play.

## v6.7 source package

`v6.7-source/` contains the complete 15-file ZIP supplied for the September 2026 rulebook and card retry, extracted so each document is readable on GitHub. It includes superseded v3.1 material, the v6.7 base rules and card manifests, a v9.8 Advanced Circuit document from that earlier design line, and project trackers. Version labels within those files describe their historical package, not the current repository release.

## v6.7 retry

`v6.7-retry/` contains the September 2026 text-first playtest draft: a reorganized rulebook retaining the v6.7 source rules, a CSV transcription, and a 236-card prototype PDF. Its original source has an unresolved five-core-slot versus four-fashion-slot conflict. Its Stage and Queen designs, victory target, and card counts also differ from the current v7.8 edition. **Do not mix these cards with v7.8, Solo Circuit, or the v7.9 candidate.** The draft is an archival experiment, not a replacement for current components.
