# HAUTE & HAZARD: DOCUMENTATION PACKAGE
## Version 6.7 Base + Version 9.8 Advanced - January 10, 2026

---

## EXECUTIVE SUMMARY

This documentation package represents a significant clarification of the Haute & Hazard game design, establishing the correct ruleset hierarchy and reverting inappropriate balance changes that were based on misunderstood simplified rules. The game features two distinct play modes: the v6.7 Base Game providing streamlined five-phase deck-building gameplay, and the v9.8 Advanced Circuit expansion adding sophisticated ballroom simulation mechanics.

The previous version 3.1 documentation has been superseded entirely, as it was based on an incorrect interpretation of the game's complexity level and applied balance patches to mechanics that did not exist in the actual game design.

---

## DOCUMENT INVENTORY

### Core Rulebooks

**Haute_Hazard_Base_Rulebook_v6.7.md**
Comprehensive base game documentation covering the five-phase turn structure, Master versus Deep Storage card stacking logic, Dragdagulan combat system, and complete character roster of eleven Queens. This document represents the foundational gameplay experience and should be considered the authoritative reference for all base mechanics.

The base rulebook includes detailed explanations of the Coordinate system (five persistent core slots plus one temporary accessory slot), the Grand Finale round-ending trigger, Instant Slay mechanics that allow claiming Stages before Phase 4, and the complete Triple Threat ability structure (Play, Matching, Fusion) that appears on all fashion cards.

**Haute_Hazard_Advanced_Circuit_v9.8.md**
Expansion rulebook documenting the ballroom simulation layer that transforms the base game into a sophisticated strategic experience. This includes the Ball House drafting system (twelve unique houses with two-card Vaults and passive abilities), the Category Deck running parallel to Stages, Tens Tokens as a flexible resource economy, Vogue keyword mechanics for dynamic Master card swapping, and the Realness keyword providing combat penalty protection.

The Advanced Circuit modifies the base five-phase structure with integrated mechanics rather than replacing it, maintaining backward compatibility while adding strategic depth for experienced players who have mastered the v6.7 foundation.

### Card Reference Materials

**Card_Manifest_Original.txt**
Complete database of all 236 cards in the game with original balance values restored. This document supersedes the version 3.1 manifest that incorrectly applied balance changes to the Necropolis brand (reverting the +1 Appeal buffs), Rat Tail Purse (removing the "once per turn" restriction that was never part of the design), and Feather Boa (removing the +3 Defense cap that was inappropriately introduced).

The manifest is organized by Tenet (brand color) and rarity tier, with each card entry including cost, slot type, Tips and Appeal generation, LS Points for combat, Triple Threat ability text, lyric snippets for battle performance, and flavor text. All cards reflect the intentional design balance as established in the production bible documents.

## DESIGN CLARIFICATION CONTEXT

The version 3.1 documentation package created on January 9, 2026 was based on an incomplete understanding of the game's mechanical complexity. That version documented a simplified ruleset that did not include Deep Storage mechanics, stacking logic, the Grand Finale round structure, or the sophisticated resource economy present in the actual game design.

Consequently, the balance changes applied in v3.1 (Rat Tail Purse restriction, Necropolis buffs, Feather Boa cap) were addressing perceived balance issues in a game system that does not exist. These changes have been completely reverted in favor of the original card values as designed in the production bible specifications.

The correct game design features substantially more strategic depth than initially documented, with the v6.7 base rules providing a complete standalone experience and the v9.8 Advanced Circuit offering optional expansion complexity for players seeking ballroom simulation mechanics.

## FILE USAGE RECOMMENDATIONS

**For New Players**
Begin with Haute_Hazard_Base_Rulebook_v6.7.md to learn the five-phase turn structure, core card mechanics, and Coordinate building fundamentals. The base game provides sufficient complexity for multiple play sessions before introducing advanced mechanics.

**For Experienced Players**
After mastering the base game through five to ten sessions, introduce Haute_Hazard_Advanced_Circuit_v9.8.md gradually. Start with Ball House selection to understand the Vault system, then add the Category Deck in subsequent games, followed by Vogue and Realness keywords once players are comfortable with the dual challenge structure.

**For Card Reference**
Use Card_Manifest_Original.txt as the authoritative source for all card statistics, costs, and ability text. This document includes complete Triple Threat boxes and should be consulted when resolving any card interaction disputes during gameplay.

**For Project Management**
The project tracker reflects the current documentation phase at eighty-five percent completion. The immediate priority is creating a professional Word document version of the base rulebook with visual design elements (Task T023), followed by structured playtesting of both the base game (Task T024) and advanced expansion (Task T025) to validate mechanical interactions and gather data for potential future refinements.
