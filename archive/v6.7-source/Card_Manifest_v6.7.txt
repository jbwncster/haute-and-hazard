HAUTE & HAZARD: MASTER CARD MANIFEST (v6.7)
"The library is open."

This document contains the complete card database for Haute & Hazard, including card text, mechanics, quantities, and flavor text organized by Tenet (brand) and rarity tier.

====================================
VERSION NOTES
====================================

Version 6.7 represents the current production baseline with all balance changes from version 3.1 REVERTED to original design values. This manifest reflects the game's intended mechanical balance as specified in Production Bible v6.7.

Key reversions from v3.1:
- Rat Tail Purse: No longer has "once per turn" restriction (unlimited use restored)
- Necropolis brand: All cards restored to original Appeal values (v3.1 +1★ buffs removed)
- Feather Boa: No longer capped at +3 Defense (unlimited scaling restored)
