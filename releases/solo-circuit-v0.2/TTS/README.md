# Haute & Hazard - Solo Circuit v0.2 for Tabletop Simulator

Experimental add-on for the v7.9 TTS base.

Load `Haute_Hazard_v7_9_TTS_Playtest.json`, then Additive Load `Haute_Hazard_Solo_Circuit_v0_2_TTS_AddOn.json`. The add-on contains the 18-card Automa deck, 12 Personality cards, House Wardrobe marker, four-round Stage Timer, difficulty reference, House Appeal reference, and Dragdagulan† reminder.

Source/schema QA is complete. An in-app TTS smoke test is still required before labeling runtime verified.
