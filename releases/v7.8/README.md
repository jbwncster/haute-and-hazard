# Haute & Hazard v7.8 — Game Crafter Print Edition

**Status: current Game Crafter print edition / unpublished playtest prototype.**

This release is the updated Game Crafter production package for the current physical playtest.

## Physical component structure

- **Rules** — 1 Medium Folio Set
- **Haute & Hazard** — 240-card Poker Deck
- **Stages** — 12-card Holographic Foil Euro Poker Deck
- **The Queens** — 12-card Jumbo Deck
- **Player Aid** — 5 double-sided Postcard Mats
- **Box** — 1 Medium Prototype Box

## Core systems preserved

- Tenet / Brand color system
- Tips and the Shopping cost economy
- Appeal, Matching, Perfect Illusion, and Fusion
- Dragdagulan using printed LS on the three battle-drawn cards plus explicit LS modifiers

## v7.8 changes

- Stages are now **venues** rather than challenge names.
- The 12-Stage deck is balanced 3 Pink / 3 Blue / 3 Purple / 3 Yellow and covers every Base Game Brand.
- Stages use Favored Tenet, Featured Brand, Slay Target, Reward, Venue Effect, Judge, Spotlight, Judge's Favor, and Brand Ovation.
- All 12 Jumbo Queens retain their established personas and receive a **Special Appeal — Once Per Game** in addition to their Signature Ability.
- Player Aid and Medium Folio quick rules are updated to match.
- The Game Crafter component structure remains: Rules / Haute & Hazard / Stages / The Queens / Player Aid / Box.

## Binary print package

The production archive is named `Haute_Hazard_v7.8_Game_Crafter_Print_Edition.zip`. It contains the upload-ready JPG assets, safe-zone proofs, source references, checksums, and documentation.

The repository integration used to prepare v7.8 can write repository text but cannot transfer the local binary ZIP/JPG production package. The archive therefore still needs to be manually attached or committed as a release artifact. See `RELEASE_STATUS.md` for the current status.

## Version note

**v7.7.1 is archived and superseded by v7.8 for Game Crafter production.** It remains in the repository only for historical comparison and troubleshooting older proofs. Core/TTS v7.7 materials remain available until those packages receive their own v7.8 conversion.

This is an unpublished playtest prototype. Components, wording, and balance may change after testing.
