# Haute & Hazard v7.8 — Physical + Tabletop Simulator Playtest Edition

**Status: current physical and digital playtest target / unpublished prototype.**

v7.8 is the current rules/component target across the Game Crafter physical prototype and the Tabletop Simulator playtest build.

> **† Legal/IP review:** `Dragdagulan` is working prototype terminology credited to *Drag Den Philippines*. It is subject to legal/IP, trademark, and publisher review before commercial release and may be renamed. See [`../../docs/ATTRIBUTIONS.md`](../../docs/ATTRIBUTIONS.md).

## Physical component structure

- **Rules** — 1 Medium Folio Set
- **Haute & Hazard** — 240-card Poker Deck
- **Stages** — 12-card Holographic Foil Euro Poker Deck
- **The Queens** — 12-card Jumbo Deck
- **Player Aid** — 5 double-sided Postcard Mats
- **Box** — 1 Medium Prototype Box

## Core systems preserved

- Tenet / Brand color system
- Tips and the Shopping cost economy
- Appeal, Matching, Perfect Illusion, and Fusion
- **Dragdagulan†** using printed LS on the three battle-drawn cards plus explicit LS modifiers

## v7.8 changes

- Stages are **venues** rather than challenge names.
- The 12-Stage deck is balanced 3 Pink / 3 Blue / 3 Purple / 3 Yellow and covers every Base Game Brand.
- Stages use Favored Tenet, Featured Brand, Slay Target, Reward, Venue Effect, Judge, Spotlight, Judge's Favor, and Brand Ovation.
- All 12 Jumbo Queens retain their established personas and have a **Special Appeal — Once Per Game** in addition to their Signature Ability.
- Player Aid and Medium Folio quick rules match the current systems.
- A **Beginner Mode** uses the same components while temporarily ignoring Judge, Spotlight Requirement, Judge's Favor, and Brand Ovation.

## Tabletop Simulator v7.8

The current TTS build is now **v7.8** and mirrors the current physical prototype's:

- 240-card Poker Deck structure: 60 starter / 144 Wardrobe / 16 Thrift / 20 Penalty;
- 12 venue Stages;
- 12 current Queens and Special Appeals;
- current Player Aid wording;
- current Beginner Mode and full Stage systems;
- Tenet/Brand, Shopping, Look-state, Slay, and **Dragdagulan†** rules.

The package is named:

`Haute_Hazard_v7.8_TTS_Playtest.zip`

TTS source/status files are maintained in [`TTS/`](TTS/). The complete ZIP also contains the image assets, installers, standard save, teaching save, asset manifest, and QA report. If the binary ZIP is not yet attached to GitHub, the `TTS/` folder remains the authoritative source/status record for the conversion.

The old v7.7 TTS ZIP remains in `../v7.7/` only as a legacy comparison build.

## Beginner Mode

For a first playtest, use [`../../docs/BEGINNER_MODE.md`](../../docs/BEGINNER_MODE.md).

In Beginner Mode, read only these five Stage fields:

- Favored Tenet
- Featured Brand
- Slay Target
- Reward
- Venue Effect

Ignore Judge, Spotlight Requirement, Judge's Favor, and Brand Ovation for that game. All other systems stay active, including Tenets/Brands, Shopping, Matching, Perfect Illusion, Fusion, Queen abilities, Special Appeals, Slay, and **Dragdagulan†**.
