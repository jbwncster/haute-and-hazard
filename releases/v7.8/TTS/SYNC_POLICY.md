# Generated package handoff

The v7.8 TTS package is built from the current v7.8 Game Crafter component images. To keep physical and digital builds synchronized, regenerate the TTS assets from the same physical source set whenever a v7.8 card image is revised; do not independently edit the TTS image sheet and physical card art in different directions.
