# v7.8 TTS source/status files

The complete v7.8 TTS binary package is generated separately because it contains image assets too large for the connected GitHub text workflow. This directory records the current build metadata and installers.

Files:
- `README.md` — build/use overview
- `BUILD_MANIFEST.json` — component/build alignment
- `TTS_QA_REPORT.txt` — QA and runtime-test note
- `BINARY_PACKAGE.txt` — package size/checksum
- `INSTALL_WINDOWS.ps1` — packaged Windows installer source
- `INSTALL_UNIX.sh` — packaged Unix installer source

The actual generated ZIP is `Haute_Hazard_v7.8_TTS_Playtest.zip`.
