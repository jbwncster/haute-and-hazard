# Haute & Hazard v7.9 — Changelog

## Rules / economy
- Reworked Tips into a **Power-like resource generated by playing cards during Transformation**.
- Every Poker card has an explicit printed Tip value, including 0.
- Unplayed cards generate no printed Tips; already-equipped Masters do not regenerate Tips.
- Fashion can be played for Tips without being equipped, then archives at Cleanup.
- Purchases go to Backstage Archive and enter a later draw cycle.

## Wardrobe
- Rebuilt the 144-card Wardrobe as **130 unique Fashion + 14 unique Actions**.
- Removed repeated same-garment copies from the current design target.
- Preserved Brand strategic identities while differentiating individual cards.

## Starter deck
- Basic Beat: printed Tip 1.
- Messy Lip Sync: printed Tip 0.
- Chapstick: printed Tip 1.
- Basic Beat is a clean printed-Tip starter; Chapstick generates its printed Tip when played before resolving any Equip effect.

## Components
- Base Poker Deck remains 240 cards.
- Stages remain 12.
- Queens remain 12.
- Player Aids remain 5.

## Solo
- Solo Circuit advanced to **v0.2**.
- Four-round Stage timer.
- House Base Appeal = `max(0, Slay Target - 6)`.
- Explicit House Stage scoring.
- 18 Automa + 12 Personality cards remain separate from the base Poker Deck.

## Documentation
- Repository README, Start Here, Learn to Play, Beginner Mode, feedback, contribution form, publisher materials, TTS guidance, and release records aligned to v7.9.
