# Haute & Hazard — Solo Circuit Playtest Plan

**Purpose:** make Solo Circuit a strong, repeatable way to test Haute & Hazard without needing a group.

Solo players are a valuable early playtest audience because they can run repeated sessions on their own schedule. Treat Solo Circuit as a first-class testing route for the v7.9 system while it remains explicitly experimental.

## Recommended entry point

For a first Solo Circuit test:

1. Use **v7.9 Beginner Mode**.
2. Play on **Working Queen** difficulty.
3. Use the generic House Queen for the first game.
4. Add one House Queen Personality on the second game.
5. Record the short Solo feedback set after every session.

This sequence tests the core Automa before Personality variance is added.

## Three-session starter sequence

### Session 1 — Baseline

Use:

- Working Queen
- no Personality
- Beginner Mode
- a random player Queen

Record:

- winner and final score;
- number of Stages claimed by each side;
- rounds each Stage remained active;
- how often Round 4 timeout happened;
- whether the House felt threatening, weak, or arbitrary;
- rules questions and bookkeeping friction.

### Session 2 — Personality

Repeat Working Queen, but add one House Queen Personality.

Record the baseline data plus:

- how often the Personality triggered;
- whether it changed decisions;
- whether it made the House feel like a distinct rival;
- whether it added too much bookkeeping.

### Session 3 — Pressure test

Keep the same player Queen and Personality, then change only difficulty:

- **Local Girl** if the prior games felt too punishing;
- **Headliner** if the prior games felt too easy.

Do not change multiple balance variables at once unless the goal is explicitly exploratory.

## Core Automa questions

The Automa should be judged on five things:

1. **Competitive pressure** — does the House threaten Stages without feeling predetermined?
2. **Low upkeep** — can the House turn be resolved quickly without simulating a second player?
3. **Meaningful interference** — does Wardrobe removal create decisions instead of random annoyance?
4. **Personality** — do behavior cards and House Queen Personalities create a recognizable rival?
5. **Replayability** — after finishing, does the player want to immediately try another Queen, Personality, or difficulty?

## Metrics to watch

Across sessions, track:

- player win rate;
- House win rate;
- House Stage win rate;
- average rounds per Stage;
- Round 4 timeout rate;
- average player vs. House Appeal at resolution;
- number of Wardrobe removals that affected the player's plan;
- Dragdagulan† attempt rate and win rate;
- Personality trigger rate;
- average play time;
- number of rulebook lookups;
- number of Automa decisions requiring designer interpretation.

## Development targets

These are evaluation targets, not automatic balance rules:

- **Working Queen** should feel competitive for an experienced player without requiring perfect play.
- Most Stages should resolve through player or House performance rather than repeated automatic timeouts.
- A normal House turn should be substantially faster than running a second human deck.
- Personality effects should be memorable without becoming a second rules engine.
- A solo player should be able to complete a session without designer assistance.

If the numbers miss these targets, change one variable at a time and retest.

## Recruitment priority

When asking for outside playtests, explicitly invite:

- dedicated solo board gamers;
- players comfortable testing Automa systems;
- players willing to run the same setup more than once;
- players who enjoy deck-building games even if they cannot assemble a regular group.

A solo tester does **not** need prior multiplayer experience with Haute & Hazard.

## Minimum useful report

A solo playtest is still useful if the tester only reports:

- build/version;
- difficulty;
- player Queen;
- House Queen + Personality;
- winner/final score;
- Stages claimed by each side;
- game length;
- one confusing thing;
- one fun thing;
- whether they would play Solo Circuit again.

More detailed data is welcome, but a short report is better than losing a tester to paperwork.

## Current status

Solo Circuit v0.2 remains an **experimental playtest module**. The goal of this plan is to gather enough independent solo data to decide what belongs in a later v0.3 rather than assuming the current Automa is finished.
