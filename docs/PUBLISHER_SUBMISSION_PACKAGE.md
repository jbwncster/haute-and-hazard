- every legacy ZIP;
- old v7.7 material unless requested;
- raw art/source files;
- speculative expansions;
- unrelated design notes;
- the internal project tracker unless the publisher wants process/playtest evidence;
- the full project bundle when a lighter submission is requested.

## Start Here copy

> Haute & Hazard is a 2–5 player competitive drag fashion deck-building game by Jake Weiner. Players build wardrobes from a shared market, assemble persistent Looks, Slay venue Stages, and challenge rivals in Dragdagulan† Lip Sync battles. The game is an unpublished v7.9 prototype in active playtesting; balance, wording, components, art, terminology, and legal/IP-reviewed elements remain open to publisher development.

## Publisher-facing legal/IP note

> † Working prototype terminology; credited and subject to legal/IP, trademark, and publisher review before commercial release. The related card-game mechanic and rules implementation are original to Haute & Hazard.

## Submission principle

Send only what a publisher asks for. If they ask first for a sell sheet, do not attach the whole repository or the full project bundle.
