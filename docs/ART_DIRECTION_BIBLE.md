# Haute & Hazard — Art Direction Bible

This is a prototype art-direction guide, not final production art.

## Visual promise

Haute & Hazard should feel like:

- drag performance as combat;
- fashion editorial colliding with nightlife spectacle;
- camp, glamour, danger, and wit;
- readable cards first, maximal style second.

## Core palette

Suggested foundation:

- Black / charcoal for drama and table contrast.
- Ivory or warm off-white for readable text panels.
- Antique gold for frame, score, and prestige accents.
- Four Tenet colors kept distinct and colorblind-aware.

## Tenet direction

| Tenet | Direction |
|---|---|
| Pink | Pop, sugar, idol, digital brightness. |
| Blue | Horror, necro-glam, slasher, void, moonlit edge. |
| Purple | Luxury, velvet, royalty, trap, decadence. |
| Yellow | Trash couture, carnival, swamp, thrift alchemy. |
| Neutral | Utility, backstage, glue cards, visual restraint. |

## Card readability hierarchy

1. Card name.
2. Type/slot.
3. Cost, Tips, Appeal, LS, SP.
4. Tenet and Brand.
5. Rules text.
6. Flavor/art detail.

Rules text must remain readable in print and TTS.

## Queen portraits

Queens should read as full drag personas, not generic fantasy classes. Each portrait should imply:

- performance identity;
- fashion silhouette;
- Signature Tenet;
- emotional attitude;
- stage presence.

Avoid leaning on real-person likenesses or recognizable celebrity references unless cleared.

## Stage cards

Stages are venues, not abstract challenges. They should quickly communicate where the performance is happening.

Examples:

- ballroom
- nightclub
- haunted hotel
- thrift superstore
- opera house
- leather bar
- arcade

## Iconography

Icons should support rules clarity. Do not create symbols so ornate that players have to relearn the rules from the art.

## Accessibility rules

- Do not rely on color alone for Tenet recognition.
- Use icon or label support for each Tenet.
- Maintain strong text contrast.
- Keep body text large enough for tabletop distance.
- Avoid dense decorative patterns behind rules text.

## Legal/IP review

Any visual element derived from a specific third-party property, celebrity, music video, brand, show, meme, or real venue should be marked **†** and added to [`IP_REVIEW_REGISTER.md`](IP_REVIEW_REGISTER.md).
