# Haute & Hazard — Rules Clarifications and FAQ

Use this as a living document. If the same clarification appears more than once, update the rules or card text rather than letting this FAQ become a patch.

## Current standing clarifications

### Does equipped Fashion automatically add LS during Dragdagulan†?

No. Dragdagulan† Battle Score uses the printed LS on the three battle-drawn cards plus explicit active `+LS in battle` modifiers. Equipped Fashion does not automatically contribute LS unless an effect explicitly says so.

### Is Accessory required for a Complete Coordinate?

No. A Complete Coordinate requires Face, Wig, Body, and Shoes. Accessory is optional unless a card explicitly changes this.

### Can Beginner Mode remove cards?

No. Beginner Mode uses the same components. Players simply ignore Judge, Spotlight Requirement, Judge's Favor, and Brand Ovation.

### Can Matching and Fusion coexist?

Yes, if Deep Storage or another eligible effect introduces the second non-Neutral Tenet into the Fusion pool while the visible core Coordinate remains Matching.

### What happens if a term is marked †?

It is working prototype terminology or material subject to legal/IP, trademark, and publisher review before commercial release. Use it for playtesting, but do not describe it as commercially cleared.
