# Haute & Hazard — Solo Circuit House Queen Personalities v0.2

Use **one** Personality with the 18-card House Queen Automa deck. These are deliberately lighter than the player-facing Queen abilities.

| House Queen | Personality | Solo effect |
|---|---|---|
| **Lady Lux** | Treasure From Trash | Whenever the Automa removes a Market card costing 2 or less, +1 House Appeal this round. |
| **Kawaii-Bot** | Idol Perfect | Whenever the Automa removes a Pink Fashion card, gain 1 Match token. At 3, gain 1 Gross SP and clear the tokens. |
| **Mother Mortis** | From the Grave | Once per Stage, when a resolved Automa card would be discarded, set it aside. During the next round, add +1 House Appeal, then discard it normally. |
| **Opulencia** | More Is More | The first time each round an Automa effect gives House +1 or more Appeal, add +1 additional House Appeal. |
| **Velvet Venom** | Toxic Entrance | Whenever the Automa removes a Blue Fashion card, player archives 1 card from hand if able. Maximum once per round. |
| **Maldita Manila** | Duality | If House Wardrobe contains at least two non-Neutral Tenets, +1 House Appeal. If it contains all four, +2 instead. |
| **Hexa Laroux** | Perfect Geometry | Whenever House gains Gross SP, gain +1 House Appeal on the next Automa round. |
| **Bubblegum Banshee** | Sugar High | Whenever the Automa removes Pink Shoes, reveal the next Automa card and use the higher Appeal of the two; discard the extra card without resolving it. |
| **Siren Diesel** | Built to Walk | Whenever the Automa removes Shoes, +1 House Appeal this round. |
| **Opal Dynasty** | Full Spectrum | Once per Stage, when House Wardrobe contains Face, Wig, Body, and Shoes, gain 1 Gross SP. |
| **Rapture Royale** | Sacrifice | Once per Stage, discard the top Automa card without resolving it to add +2 House Appeal to the current round. Do this automatically if House would otherwise miss the Slay Target by exactly 1 or 2. |
| **Gore-Jess** | Final Girl | Whenever House wins Dragdagulan†, gain 1 Gross SP. If House wins by 3+, gain 2 instead. |

## Personality testing rule

For the first pass, play each Personality on **Working Queen** difficulty.

Record whether the Personality:

- triggered at least once;
- was easy to remember;
- changed a decision;
- produced more than 3 Gross SP or 5 Appeal by itself in one game;
- felt recognizably connected to the player-facing Queen.

If a Personality requires frequent exception handling, simplify it before increasing its power.
