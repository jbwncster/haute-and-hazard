## v7.9 rules checkpoint

Before starting, make sure every player knows:

1. every Poker card has a printed Tip value;
2. every turn begins with **Tip Count** before Transformation;
3. count each card's printed Tips once;
4. the same card may still be played/equipped afterward;
5. purchased cards go to Backstage Archive and are drawn later.

## First-session mode

Use **Beginner Mode** unless the session is specifically testing the full Stage layer.

## Minimum data

Record:

- date
- exact build/version
- physical / TTS / Solo
- player count
- mode
- game duration
- Queens
- winner and final score
- Stages Slayed
- Tip Count mistakes/double-counting
- Shopping purchases
- Dragdagulan† attempts
- most confusing moment
- most fun moment
- whether the group would play again

For Solo v0.2 also record:

- House Queen/Personality
- difficulty
- Stage Slay Target
- House Base Appeal
- Stage round resolved
- Appeal vs. timeout result
- Market removals

## Experimental modules

The alternate two-placement Stage rules remain optional and must be labeled as experimental.

Solo Circuit v0.2 is also experimental and should be logged separately from 2–5 player balance data.
