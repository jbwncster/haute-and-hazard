# Jake Weiner — Board Game Designer Branding

The official designer logo for **Jake Weiner — Board Game Designer** is:

![Jake Weiner Board Game Designer logo](images/Logo.png)

## Usage

Use this logo on new publisher-facing, playtest, promotional, presentation, and designer media created for **Haute & Hazard** unless a specific format requires a text-only treatment.

The designer logo is separate from the **Haute & Hazard** game identity. It should identify the designer or publisher-facing material without replacing the game's own title treatment, card backs, or in-world branding.

## Preferred placement

- Publisher sell sheets: top or footer.
- Pitch decks and presentations: title slide and closing/contact slide.
- Playtest handouts: footer or back page.
- Social/promotional designer posts: visible but secondary to the game title.
- GitHub documentation intended for publishers: top or closing contact section.
