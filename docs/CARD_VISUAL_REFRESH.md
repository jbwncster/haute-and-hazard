# Haute & Hazard — Card Visual Refresh

**Status:** historical v7.8 visual-refresh work retained as a design reference. Apply these visual principles to v7.9 only through a new synchronized render of the v7.9 card pool.  
**Gameplay impact:** none. Existing card names, rules text, costs, Tips, Appeal, LS, SP, Tenets, Brands, quantities, and component assignments remain unchanged unless separately changed by balance testing.

## Design goal

Use the **high-level information architecture** that makes fashion cards easy to read in Data Carddass Aikatsu!—large fashion presentation, obvious category/type identity, visible Brand identity, rarity/status cues, and a prominent performance value—without copying Aikatsu!'s artwork, characters, logos, card frames, icon drawings, fonts, QR placement, decorative motifs, exact proportions, or trade dress.

The result should feel unmistakably like **Haute & Hazard**: drag editorial, nightlife, camp, danger, glamour, and readable tabletop information.

## What the Aikatsu! cards teach us

Public Aikatsu! card references consistently surface a few pieces of information at a glance:

- the featured garment or outfit dominates the card;
- the fashion category is visually obvious;
- a style/type identity is shown prominently;
- Brand information is easy to locate;
- rarity/status is visible;
- performance value is displayed as a clear number;
- cards in the same family feel related even when their artwork differs.

Haute & Hazard should borrow only those **design principles**, not the actual visual execution.

## Non-infringement rules

Do **not** reproduce or closely imitate:

- Aikatsu! character art or silhouettes;
- official Aikatsu! logos, Brand marks, icons, badges, star graphics, card IDs, or QR treatments;
- the exact Aikatsu! frame, border, information-strip geometry, or placement pattern;
- official typefaces or decorative lettering;
- exact floral, ribbon, heart, gem, crown, lace, sparkle, or background arrangements from a specific card;
- Aikatsu! Brand names, category names beyond generic fashion terms, card names, or character names;
- scans, crops, traces, recolors, or derivatives of official card art.

Instead, build an original Haute & Hazard layout around the game's existing information.

## Core Fashion card hierarchy

Every Fashion card should preserve all current gameplay information and present it in this order:

1. **Card name**
2. **Hero fashion art**
3. **Slot** — Face / Wig / Body / Shoes / Accessory
4. **Tenet**
5. **Brand**
6. **Cost**
7. **Tips**
8. **Appeal**
9. **LS**
10. **Rules text**
11. **Status / rarity treatment if used**
12. **Card ID / prototype version / legal marker where applicable**

Nothing currently printed on a card may be removed simply to make room for art.

## Recommended original layout

### Top band — identity

- Card name across the top.
- Slot icon + written slot label near the name.
- Tenet shown through both color and a distinct Haute & Hazard symbol.
- Brand shown as text with an original mini wordmark or monogram.

This borrows the **idea** of quick categorical recognition, not Aikatsu!'s layout.

### Center — fashion-first hero area

Use roughly the central 45–55% of the card for the Fashion itself.

Preferred presentation:

- isolated garment, wig, makeup concept, shoe, or accessory shown large;
- optional secondary drag-model vignette showing how the item reads when worn;
- original editorial composition;
- no anime-character imitation;
- no replica of Aikatsu!'s garment + idol pose arrangement.

The garment should be recognizable from across a table.

### Resource rail

Use one clearly separated original resource rail for:

- **Cost**
- **Tips**
- **Appeal**
- **LS**
- **SP** only when the card actually carries it

Each value needs:

- its own original icon;
- a written abbreviation;
- high contrast;
- a fixed location across the entire deck.

The rail may be vertical or horizontal, but it should not mimic Aikatsu!'s bottom stat strip.

### Rules panel

Rules text remains fully readable.

- opaque or near-opaque panel;
- never place body text directly over detailed illustration;
- bold timing words where useful;
- preserve current wording exactly during a visual-only refresh;
- retain **†** wherever the canonical text requires it.

### Card footer

Small footer may carry:

- stable card ID;
- prototype version;
- quantity/set code if useful;
- designer/game mark;
- legal/IP marker if needed.

Use an original Haute & Hazard system rather than an Aikatsu!-style card-number treatment.

## Tenet visual language

Each Tenet needs **three redundant identifiers**:

1. color;
2. original symbol;
3. written label.

Suggested original symbol families:

- **Pink** — burst / candy-glitch spark
- **Blue** — crescent blade / gothic thorn
- **Purple** — faceted jewel / velvet crown abstract
- **Yellow** — spotlight flare / reclaimed-starburst
- **Neutral** — backstage pass / open frame

These should be newly drawn for Haute & Hazard and not based on Aikatsu!'s Cute/Cool/Sexy/Pop icons.

## Brand treatment

Aikatsu! demonstrates the value of a visible Brand field. Haute & Hazard should make its own Brands feel collectible and recognizable.

Each Brand should receive:

- a small original wordmark or monogram;
- one repeating texture family;
- one accent motif;
- consistent placement on every card of that Brand.

Do not make any Brand logo resemble an Aikatsu! Brand mark.

Current Base Game Brands remain:

- Sugar Rush
- Hyper-Glitch
- Necropolis
- Slasher
- Void
- Velvet Trap
- Gilded Cage
- Trash Can
- Big Top
- Swamp Witch

## Rarity / prestige without copying Aikatsu!

If rarity is used visually, keep it as a **Haute & Hazard production language**, not a recreation of Aikatsu!'s Normal / Rare / Premium Rare star-badge system.

Possible original treatments:

- **Backstage**
- **Spotlight**
- **Headliner**
- **Legend**

Or retain the current rarity labels if the card database already defines them.

Rarity should affect border finish, foil callout, or micro-badge treatment only unless a rule specifically says otherwise.

## Starter cards

Starter cards should be intentionally plainer than Wardrobe cards:

- less decorative framing;
- smaller or simpler art treatment;
- very clear resources;
- a visible **Dressing Room Floor** marker;
- same information locations as upgraded cards.

The player should be able to feel the visual transformation of the deck as stronger Fashion enters play.

## Wardrobe Rack cards

These get the full visual system:

- large hero Fashion art;
- strongest Brand identity;
- full Tenet treatment;
- clear cost/resource rail;
- rules panel;
- optional rarity/prestige treatment.

## Thrift Store Throwbacks

Use the same base system, but make the family visually distinct through:

- resale-tag / archive-label inspiration;
- distressed print texture;
- mismatched-but-deliberate editorial styling;
- a clear **Throwback** marker.

Do not reduce legibility.

## Penalty cards

Penalty cards should visually break the fashion fantasy without looking like a different game.

Suggested approach:

- desaturated or warning-toned frame;
- hazard-tape-inspired geometry that is original and not copied from a third-party property;
- huge penalty name;
- Final Judging SP loss prominent;
- no Fashion slot or Brand treatment unless a specific card requires it.

## Queen cards

Queen cards are Jumbo cards and should use a related but distinct hierarchy:

1. Queen name;
2. full original portrait;
3. Signature Tenet;
4. Favorite Brand;
5. Signature Ability;
6. Special Appeal — Once Per Game;
7. legal marker where applicable.

Aikatsu!'s use of a character to contextualize fashion supports the broad idea that a human figure helps the player connect identity to style, but Haute & Hazard Queen composition should be built from drag editorial portraiture, not anime-idol composition.

## Stage cards

Stage cards are venues and should not resemble Fashion cards.

They should preserve all current fields:

- Stage name;
- Favored Tenet;
- Featured Brand;
- Slay Target;
- Reward;
- Venue Effect;
- Judge;
- Spotlight Requirement;
- Judge's Favor;
- Brand Ovation.

Use a wide venue image and a clearly segmented rules structure suited to the current Foil Euro Poker format.

## Player Aids

Player Aids should echo the same icons and terminology so the visual refresh reduces learning time instead of merely decorating cards.

## Physical + TTS parity

The same information hierarchy, symbols, Brand marks, and card text must be used in:

- Game Crafter Poker cards;
- TTS card assets;
- Queen cards;
- Stage cards;
- Player Aids;
- rules examples;
- future print-and-play files.

## Migration rule — preserve current information

A visual refresh is **not** permission to simplify away existing content.

For every existing card, copy forward all canonical fields that currently apply:

- name;
- component;
- card type;
- slot;
- Tenet;
- Brand;
- cost;
- Tips;
- Appeal;
- LS;
- SP;
- quantity;
- rules text;
- status;
- legal/IP marker.

If the new layout cannot fit the existing information legibly, revise the layout—not the card's rules.

## Prototype review checklist

Before replacing any current card image:

- [ ] all existing gameplay information is still present;
- [ ] wording matches the canonical source;
- [ ] Tenet is readable without color alone;
- [ ] Brand is clearly visible;
- [ ] slot is immediately identifiable;
- [ ] Cost / Tips / Appeal / LS / SP cannot be confused;
- [ ] rules text is readable at physical card size;
- [ ] no Aikatsu! art, logo, character, icon, border, QR treatment, or copied layout remains;
- [ ] no DC artwork, iconography, typography, or card frame has been copied;
- [ ] TTS version uses the same information;
- [ ] any † material remains marked for review.

## Design shorthand

The target is:

> **Aikatsu!-level fashion readability + deck-builder information discipline + Haute & Hazard's own drag-editorial visual identity.**

Not:

> “Make an Aikatsu! card with Haute & Hazard text.”
