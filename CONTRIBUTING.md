# Playtest feedback

Thank you for testing **Haute & Hazard**.

1. Confirm that every file used in the game has the same version number.
2. Open a **Playtest report** under Issues.
3. Include player count, Queen choices, game length, final scores, and the number of Judge's Favors and Brand Ovations earned.
4. Quote the exact card or rule when reporting unclear wording.
5. Describe what happened before proposing a fix; play patterns are especially useful during balancing.

Please do not upload modified cards, unofficial builds, or third-party artwork to this repository.
